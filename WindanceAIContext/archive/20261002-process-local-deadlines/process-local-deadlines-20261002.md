# Process-local deadline correction — October 2, 2026

The staged cutoff failure was caused by exchanging absolute time.monotonic timestamps across SAL Python3.9.6 processes. Diagnostic worker timestamps became negative relative to the parent and drifted with parent age. Python documents that macOS monotonic clocks became the same for all processes only in3.10: https://docs.python.org/3/library/time.html#time.monotonic. Previous cross-process finish-time comparisons are invalid; the observed late synthetic effects remain genuine failures. No kernel signal failure was established.

Corrected the original dedicated-group guardian protocol to exchange remaining duration and establish a local deadline. Parent independently enforces the total budget from before spawn, with no previous three-second execution grace. Parent and guardian can each kill the same dedicated group. Retained the original group topology so the parent fallback covers ordinary descendants; the external-group alternative remains rejected and is not part of this correction.
