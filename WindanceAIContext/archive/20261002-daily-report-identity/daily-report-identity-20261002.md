SQLite FULL/fullfsync transactions commit the original namespace/date/recipient/body and attempting state before transport. Attempting resumes query-only with original body/key, never regenerated content or a new date. A prior unfinished report blocks a new-day send; one invocation performs at most one transport call. After a prior report is verified, that invocation returns previous_verified; a later invocation may create the current report. Completed same-day report returns without rendering/sending. Recipient change holds.
