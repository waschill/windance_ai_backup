# Deterministic authenticated conversational memory routing — staged

October 2 UTC / October 1 Mountain 2026. Phase1 open; production unchanged.

The full private manager candidate now changes only app construction and the beginning of process_messages, verified against the current installed source by AST preservation. Authenticated memory-intent messages are committed with their source evidence in memory_pending state, which the existing general worker selector does not consume. A deterministic processor runs before that selector. It reads only attested sources, uses explicit owner/business-personal scope, and records facts through the transactional source/request gateway. Ordinary requests retain queued behavior. Supported or ambiguous top-level memory commands do not fall through to the model bridge merely because parsing fails.

Initial remember commands create a stable source-derived key and personal scope by default, or explicit business scope. Reply identifies scope, record key and revision, labels the content as the owner's statement rather than independently verified truth, and provides exact correction/forgetting syntax. Changes use `correct memory <key> revision <n>: <replacement>` or `forget memory <key> revision <n>`. Target scope is resolved only among that owner's facts; revision comparison prevents stale overwrite. Forgetting clears current fact content and reports that source messages remain retained. Ambiguous unsupported requests receive a fixed no-change/no-worker explanation.

Accepted source and message are committed first. A fact write/request receipt is transactional; answer persistence follows separately. If processing fails with a storage error, memory_pending remains available for same-ID retry. If an older already-processed memory event is retried after a newer revision, it returns a superseded explanation without restoring the old content. The existing manager answer/delivery machinery handles answered messages with the stored owner; there is no second sender. Actual durable process-crash acceptance for this newly composed path remains to be verified, despite earlier component recovery evidence.
