# Bounded keyed admission and caller wait — October 2, 2026

Staged keyed_outbox_admission.py and bounded_outbox_client.submit_and_wait. The client supervises one fixed child for admission plus read-only status polling under one maximum55-second parent-local budget. Payload travels over stdin, not command arguments. Timeout kills/reaps the child and returns unknown/status_wait_expired with same-request-query guidance; no delivery/failure inference or new identity.

Admission requires existing queue/results/claims directories and schema3 journal. It uses a nonblocking keyed claim lock, rechecks identity under lock, and refuses orphaned queue/result/inflight/quarantine or journal history. Existing claims are only reconciled; claim-only history is never recreated as a queue item. New claim and queue files each flush/fsync before atomic replacement and directory fsync. This improves staged persistence ordering; actual power-loss survival is not proven. A crash between claim and queue intentionally holds work for explicit reconciliation. SMS and noncanonical whitespace inputs are rejected instead of silently changing identity.

SAL eight-case isolated tests pass: new admission waited0.505seconds under0.5budget then returned unknown while one durable request remained; a second same-key call retained identical queue bytes and no duplicate entry. Busy lock returned in0.073seconds. Claim-only, orphan result, orphan journal, conflicting body, missing journal and SMS cases created no queued request. No transport was invoked and no live outbox was touched. Existing producer/daemon remain unchanged; old unkeyed/SMS/legacy semantics are not silently replaced.

Limits before rollout: successful natural receipt from admission through the new supervised worker must still be composed, along with admission crash injection, exact caller stdout/exit-code handling and SSH timeout behavior. The55-second child budget leaves nominal space inside80-second callers, but complete transport/cleanup timing is not yet proven. A killed outer parent may leave its admission/status child briefly running; stable identity and durable records must be reconciled, never assume no publication occurred. Trusted local root/path access is not an authenticated remote API. Fullfsync hardware guarantees and malicious filesystem replacement are unproven. Updated immutable recovery package/current maintenance coordination remain mandatory. Phase1 remains open.

Published source/test packet only. No production service, schedule, real send, dispatch, SAM, Odoo, SyncThing, Level8, Warden, phone or model-route change. No application model calls or purchases; Codex dollar cost unknown.
